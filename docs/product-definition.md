# Product definition

## Product name

Luvira LINE AI Advisor

## Target

AIを基礎から理解したい中小企業の経営者。

## Purpose

経営者がAIを判断・活用するために必要な基礎を、LINEで短く継続的に届けること。

## Positioning

「経営者が最低限知るべきAIの基礎」。初心者に寄り添いつつ、子ども扱いはしない。

## MVP scope

リッチメニュー、固定返信、AI質問箱、経営者向けの短い回答を提供する。

## Future monetization

無料コンテンツで信頼をつくり、勉強会、診断、導入支援、テンプレート・研修などの有料サービスへ展開する。

## Non-goals for now

- 高度なAI実装の技術支援
- 個別の業務システム開発
- 医療・法律・税務・金融などの専門判断
