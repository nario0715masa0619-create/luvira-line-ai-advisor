# 配信管理スプレッドシート運用

## 対象

Googleスプレッドシート **AI顧問配信管理** のメインシート **LINE配信管理** を、LINEコンテンツの計画、生成、レビュー、配信可否、および重複管理の台帳として使用する。

通常配信と「あなたのAI顧問 成相のコラム」は同じカレンダーテーブルで管理し、`配信予定日` の昇順で並べる。コラム投稿は薄い背景色で視覚的に区別する。

## 主な管理列

| 区分 | 列 |
| --- | --- |
| 計画 | ID、配信予定日、曜日、カテゴリ、テーマ、狙い |
| 本文とレビュー | AI生成文、人間確認、ステータス、配信済み日時、メモ |
| 生成前の重複制約 | 重複チェック、重複候補ID、この記事だけの主張、被り禁止テーマ、差別化角度、修正方針、最終判定 |
| 実本文の重複確認 | 実投稿重複判定、被り表現/既出論点、本文固有ベネフィット、新規性スコア、再利用禁止フレーズ、言い換え禁止 |
| 配信判定と次回改善 | 投稿可否、次回生成メモ |

## 運用手順

1. 記事ID、配信予定日、カテゴリ、テーマ、狙いを登録する。
2. 過去記事を参照して生成前の重複制約を設定し、本文を生成する。
3. 本文レベルで重複を確認し、既出論点・禁止表現・新規性を記録する。
4. 人間レビューを実施し、必要な修正と再確認を完了する。
5. `人間確認 = 確認OK`、`実投稿重複判定 = OK` または `修正後OK`、`投稿可否 = 可` を満たすことを確認してから配信する。
6. 配信後に配信済み日時を記録し、次回の生成に生かす事項を`次回生成メモ`へ残す。

配信可否の条件を満たさない行は、配信対象から除外する。
