# LINE rich menu

## Layout

| 行 | ボタン |
| --- | --- |
| Top | AI診断 / 社長プロンプト / AI質問箱 |
| Bottom | AIルール / 今週まとめ / お知らせ |

## Button action texts

| 表示名 | 送信テキスト |
| --- | --- |
| AI診断 | AI診断 |
| 社長プロンプト | プロンプト |
| AI質問箱 | AI質問箱 |

| お知らせ | お知らせ |

## Rule

アクションテキストは短いキーワードだけにする。長い返信メッセージをリッチメニューへ持たせず、n8nのKeyword Switchと固定返信で管理することで、更新を一か所に集約できる。
