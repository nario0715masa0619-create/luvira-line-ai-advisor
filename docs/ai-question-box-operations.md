# AI質問箱運用

## 現在の回答方針

AI質問箱のn8nワークフローでは、OpenAIモデル `gpt-4o-mini` を使用する。現段階では、経営者向けの短く初心者にも分かりやすい回答が目的のため、上位モデルは不要と判断している。

回答はおおむね120文字とし、専門用語を避ける。複雑な推論を必要とする回答は前提にしない。

## 利用範囲と規模

公式LINEアカウントを友だち追加した利用者は、AI質問箱へ質問でき、AIから返信を受ける。現在は小規模・デモ運用として許容する。

以下のいずれかを超えたときは、追加のガードレールを見直す。

- 友だち数が30人超
- 1日の質問数が20件超

見直し時に検討するガードレールは次のとおり。

- 個人情報・機密情報を入力しないよう案内する
- 回答範囲をAI活用、業務効率化、経営者向けAIの質問に限定する
- 関係のない質問や不適切な質問には短く回答を断る
- 質問数を記録する
- 利用者ごとの連続質問数に上限を設ける

これらのガードレールを導入する際も、認証情報、トークン、Webhookシークレットなどの機密値は文書やリポジトリに記録しない。
